# ⚽ FIFA World Cup 2026 – Landing Page

![FIFA World Cup 2026 landing page](assets/screenshot.png)

A responsive landing page for the **FIFA World Cup 2026**, designed to showcase the tournament, host cities, key matches and star players.

> ⚠️ This is an educational project and is not affiliated with or endorsed by FIFA.

## 🔗 Links

- **Live Demo:** https://samin7654.github.io/fifa-world-cup/
- **GitHub Repository:** https://github.com/samin7654/fifa-world-cup

## 📖 Overview

This project is a front-end landing page that promotes the FIFA World Cup 2026, hosted across the USA, Canada and Mexico. Visitors can see tournament stats, explore host cities, check upcoming key matches and meet the biggest football stars.

## ✨ Features

- Responsive navigation bar with a "Buy Tickets" call-to-action
- Hero section with the tagline "One Game. 48 Nations. One World."
- Tournament statistics (tickets sold, stadium capacity, live coverage hours, fan satisfaction)
- **Host Cities** section: New York / New Jersey, Mexico City, Toronto and Vancouver
- **Matches to Circle** schedule table (date, match, venue, stage)
- **Top Class Players** cards (Messi, Ronaldo, Neymar, Mbappé, Yamal, Kane, Hakimi, Haaland)
- Footer with social links, Terms & Conditions and Privacy Policy

## 🛠️ Technologies Used

- **HTML5** – page structure
- **CSS3** – styling, Flexbox/Grid, responsive layout
- **GitHub Pages** – hosting

## 📦 Dependencies

This project has **no external dependencies**. It is built with plain HTML and CSS, so no installation or build step is needed.

## 🚀 Run Locally

1. Clone the repository:
```bash
   git clone https://github.com/samin7654/fifa-world-cup.git
```
2. Go to the project folder:
```bash
   cd fifa-world-cup
```
3. Open `index.html` in your browser (double-click it, or use the VS Code **Live Server** extension).
